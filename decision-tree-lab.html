可审计的路径

从根到叶的每一次选择，都是对样本空间的一次切分。理解树，先理解“递归划分”这四个字。

概念块 / CONCEPT

根节点、内部节点、叶节点

决策树是一种基于特征递归划分样本的树形判别模型。根节点包含训练全集 ；内部节点选择一个特征与判定条件，把当前样本集送到不同的子节点；叶节点输出类别。每条从根到叶的有向路径，都是一条可以写成 的规则。

例如 PlayTennis 中的一条路径是：Outlook = Sunny → Humidity = High → No。它等价于规则：如果天气晴朗且湿度高，则不组织打球。决策树因此常被称为白盒模型：分类依据可以被逐条检查，而不是只能观察输入输出。

但“白盒”不等于“永远好解释”。树越深、叶节点越多，规则数量和交互关系越复杂，人工审计成本也会上升。工业上限制树深、设置叶节点最小样本数，既是在控制过拟合，也是在维持可解释性。

02PURITY

不纯度描述“当前节点有多乱”；信息增益、增益率与 Gini 减少量描述“这次划分值不值”。两件事不要混为一谈。

熵：熵越大，类别分布越混乱；样本全同类时 。二分类时最大值为 bit，且只当正负样本各占 50% 时取到；若是 类且均匀分布，最大值为 ，不要一概写成 1。

Gini：基尼指数同样在不纯度越低时越小，纯节点为 0。二分类时最大值为 ，在正负样本各占 50% 时取到； 类均匀分布时最大值为 。它只含平方与求和，通常比含对数的熵更容易计算。CART 分类树使用 Gini。

注意：熵与 Gini 是两种不同的不纯度尺度，数值不能直接横向比较。二分类 50/50 时，，而 ，二者都达到各自的最大值。

从“不纯度”到“分裂准则”

信息增益越大，说明划分后子集越纯；C4.5 用固有值 惩罚“取值很多、把样本切得很碎”的特征；CART 分类树则在所有候选二叉切分中最大化 。回归树的 CART 使用平方误差的减少量，而不是 Gini。

ID3 的偏置：为什么它会偏爱“取值多”的特征

信息增益天然偏向取值数多的离散特征。设想给每个样本编一个唯一编号，按编号分裂会把每个子集都切成只有一个样本的纯节点，信息增益达到 ；但这组规则对新样本几乎没有泛化能力。

C4.5 用增益率缓解这个问题；不过增益率也可能过度惩罚取值少的特征。常见实现会先用信息增益筛掉低于平均水平的候选，再比较增益率。工程上不要只看公式名称，还要看具体实现。

算法分裂准则树结构数据支持关键特性与缺陷
ID3信息增益多叉树仅离散特征原生无内置剪枝；偏好取值多的特征，易过拟合
C4.5信息增益率多叉树离散 / 连续，支持缺失值用固有值抑制多取值偏置；多叉树训练效率较低，工业实现少
CARTGini（分类）/ 平方误差（回归）严格二叉树分类、回归双任务特征可在不同节点重复分裂；单棵树方差大、稳定性弱
关键区别 / NOT JUST A NAME

多叉 vs 二叉：一条分裂就能改变解释方式

ID3 与 C4.5 对离散特征采用多路划分：Outlook 有三个取值，就一次产生三个分支。CART 只允许二叉划分，因此会问“Outlook 是否为 Overcast？”这类是/否问题；一个特征可以在不同深度被多次使用。

CART 是“二叉树”，不是“只能做二分类”。分类任务输出多个类别时，叶节点仍然可以给出多类别之一；它的“二”指的是每个内部节点只有两个孩子。scikit-learn 的决策树实现属于 CART 系，默认使用 Gini，也支持通过 criterion="entropy" 改用熵，但树仍然是二叉的。

为什么不用任意阈值？对一维连续特征，只需检查排序后相邻取值的中点；在这些候选点之间移动阈值不会改变左右样本集合。CART 用 Gini 减少量选切点，C4.5 则用信息增益率选切点。

05PRUNING
复杂度 / GENERALIZATION

树越深越准吗？
训练分数不等于泛化能力

过拟合的树会把噪声和异常样本也编进规则。剪枝是在“训练误差”与“模型复杂度”之间做交易。

过拟合 / OVERFITTING

无限生长，会把训练集的偶然性当成规律

如果一直分裂到每个叶节点都纯，树会记住训练样本中的噪声、异常点与偶然组合。训练误差可能降到 0，但在测试集或真实业务上，决策边界会变得过于细碎，方差显著上升。常见信号包括：树很深、叶节点样本很少、训练准确率与验证准确率差距拉大、换一批数据后分裂特征明显变化。

剪枝有两类。预剪枝在训练过程中提前停止：限制最大深度、要求内部节点最少样本数、限制叶节点数。后剪枝先长成完整树，再自底向上评估是否把子树替换成叶节点。预剪枝便宜，但可能因为“目光短浅”而欠拟合；后剪枝计算更贵，通常能避免过早停止带来的视界受限问题。

工程落地 / WHERE IT MATTERS

白盒的价值，在于“可追溯”而不只是“看起来简单”

决策树适合需要输出可解释判定依据的场景：金融风控中的规则型拒绝理由、医疗辅助诊断中的风险因素排序、合规审批中的条件核查。这里的关键不是“树一定比深度学习更准”，而是模型输出可以被业务人员、审计人员或患者理解并复核。实际系统仍需要数据治理、外部验证、阈值校准和人工兜底。

同时要承认单棵树的局限：它对训练数据的小扰动敏感，方差大，稳定性弱。工业界常用集成方法降低方差或偏差：随机森林通过 Bagging 与特征随机化组合多棵树，GBDT 通过 Boosting 逐轮修正残差。它们是后续集成学习章节的直接基础。

单棵决策树→Bagging / 随机森林→Boosting / GBDT→XGBoost / LightGBM 等工程实现

一句话带走：树深增加会降低训练误差，但不保证降低泛化误差。预剪枝控制“何时停”，后剪枝控制“长完以后删什么”，验证集负责选择复杂度。

scikit-learn 的树是“CART 系”的实现

下面的代码使用 DecisionTreeClassifier。默认 criterion="gini" 对应 CART 分类树的 Gini 不纯度；即使改成 criterion="entropy"，树仍然是二叉的，只是选择分裂时改用信息熵。不要把“准则”与“树形”混为一谈。

Iris 的四个特征都是数值型，因此可以直接训练。真实数据中的字符串类别通常需要先编码；缺失值、类别不平衡和特征尺度也需要单独处理。这里的 max_depth=3 是一个显式的预剪枝设置。

PYTHON 3.10+ / iris_decision_tree.py
# 需要：Python 3.10+，scikit-learn 1.x
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score

iris = load_iris()
X, y = iris.data, iris.target

# stratify=y 保持训练/测试集中的类别比例一致
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y
)

clf = DecisionTreeClassifier(
    criterion="gini",   # CART 分类树的不纯度准则
    max_depth=3,        # 预剪枝：限制最大深度
    random_state=42
)
clf.fit(X_train, y_train)

y_pred = clf.predict(X_test)
print(f"test accuracy: {accuracy_score(y_test, y_pred):.3f}")
print(f"depth: {clf.get_depth()}, leaves: {clf.get_n_leaves()}")

# Gini importance：各特征对总不纯度下降的归一化贡献
for name, importance in zip(iris.feature_names, clf.feature_importances_):
    print(f"{name:>18}: {importance:.4f}")

读代码时抓住 5 个点

  1. 先划分，再训练：stratify=y 避免某一类在测试集中过少，固定 random_state 保证可复现。
  2. 准则不是树形：gini 或 entropy 只改变不纯度评分；scikit-learn 仍然生成二叉 CART 树。
  3. 深度是预剪枝：max_depth=3 是工程上常见的复杂度控制。真实调参应做验证曲线或交叉验证。
  4. 特征重要性不是因果：Gini importance 衡量的是不纯度下降的总贡献，相关特征可能分摊重要性，不能直接解释为“特征导致结果”。
  5. 输出只是起点：准确率之外，还应检查混淆矩阵、类别召回率、树结构和业务约束。
示例输出（scikit-learn 1.8.0）：test accuracy ≈ 0.978；feature importances ≈ [0, 0, 0.5509, 0.4491]。不同版本或数据划分可能略有差异。
自检三问：能不能用自己的话答出来？

1. 二分类正负各占 50% 时，熵和 Gini 分别是多少？
信息熵为 1 bit，Gini 为 0.5。它们都达到二分类场景各自的最大值，但不是同一个尺度。

2. 为什么 ID3 会偏爱取值多的特征？
因为按多取值特征切分容易产生更纯的小子集，信息增益可能很高；极端情况下，唯一编号可以把每个样本切成单点纯节点。C4.5 用固有值惩罚这种“切碎”倾向。

3. 为什么训练准确率不能单独证明模型好？
树越深越容易拟合训练噪声，训练准确率上升不代表测试集/真实数据上的泛化误差下降。应结合验证集、测试集和模型复杂度一起判断。
